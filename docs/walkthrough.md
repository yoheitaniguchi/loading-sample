# React Focus Loading PoC Walkthrough

このドキュメントは、作成された「フォーカス制御付きローディングPoC」の概要と検証手順を説明します。

## 概要
このアプリケーションは、React Context APIを使用してローディング状態とフォーカス制御を一元管理することで、UIロジックとビジネスロジックの分離を実現しています。

## 実装内容
### 1. ディレクトリ構造
- `src/context/`: `LoadingContext` (フォーカス管理の中核), `ProductContext` (データ管理)
- `src/components/Layout/`: grid レイアウト
- `src/components/Features/`: 検索, 一覧, コマンドバー
- `src/components/UI/`: オーバーレイ表示

### 2. 主要機能
- **自動フォーカス復帰**: `LoadingContext` がローディング開始時のフォーカス要素を記憶し、終了時に復元します。
- **無限ループ防止**: `SearchFilter` コンポーネントにて、フォーカスイベントによる再ローディングを適切なデバウンス処理で防止しています。
- **モックデータ更新**: `ProductByContext` を通じて、登録アクション時にデータの更新日を変更します。
- **[NEW] 条件付きフォーカス制御**: 検索項目6では、ローディング後にエラーを表示し、フォーカスを項目5へ移動させる（自動復帰無効）フローを実装しました。
- **[NEW] サイドバー開閉**: デスクトップ環境でもバーガーメニューでサイドバーの表示/非表示を切り替え可能です。

## 検証手順 (ユーザー側で実施)

### 前提条件
- Node.js がインストールされていること。

### 手順
1. 以下のコマンドで依存関係をインストールし、サーバーを起動します。
   ```bash
   cd loading-sample
   npm install
   npm run dev
   ```
2. ブラウザでアプリケーションを開きます。
3. **検索フィールド (項目1~5)**をクリックし、ローディング表示後にフォーカスが戻ることを確認します。
4. **検索フィールド (項目6)**をクリックします。
   - ローディング(3秒)が表示されます。
   - ローディング終了後、ブラウザの警告ダイアログ「エラーが発生しました」が表示されます。
   - ダイアログを閉じると、**項目5**にフォーカスが移動していることを確認します（この時ローディングは発生しません）。
5. **バーガーメニュー (左上)**をクリックし、サイドバーが開閉することを確認します。
6. **登録ボタン**をクリックし、同様にフォーカスが戻ることを確認します。

### 自動テスト検証結果
以下のコマンドで自動テストを実行し、全ケースの通過を確認しました。
```bash
npm test
```

- **SearchFilter Test**:
  - 項目1へのフォーカス復帰 (3秒ローディング後)
  - 項目6へのエラー表示とフォーカス移動 (3秒ローディング後、自動復帰なし)
- **AppLayout Test**:
  - バーガーメニューによるサイドバーの表示切り替え (初期状態: 表示 -> 非表示 -> 表示)

## 技術的ポイント
- `useRef` を使用して `document.activeElement` を保持することで、Reactの再レンダリングサイクルの影響を受けずに確実にフォーカスを復元します。
- CSS Modules を採用し、スタイルの競合を防いでいます。
